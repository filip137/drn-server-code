# Series 003 — Clean EqProp beta response

This series measures saved clean-training checkpoints to understand the
mechanism relevant to beta selection. It is separate from the endpoint-noise
qualification plans in series 002. The source p90 training uses zero read
noise; p90 names the original cosine-selection threshold, not a noise level.

[exp-006](experiments/exp-006-rms-and-cosine-beta.md) compares three schemes,
two stages and a common beta grid, at fixed T=K=8. It is explicitly authorized
by Filip's request to implement the September 24 plan. There is no new
training, official-test evaluation, or T/K experiment.
